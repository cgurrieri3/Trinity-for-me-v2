static float IUtilities::GetPedestalAverage ( std::vector< int >  trace,
int  tWindow = 20,
int  pad = 10,
bool  isUnCorrelated = true 
)
static

Public method to calculate the pedestal based on the algorithm developed for uncorrelated samples in a trace The average of all samples in the specified time window is calculated.

If isUnCorrelated is true, then the following pad samples are skipped. The process is repeated for the length of the trace std::vector. The std::vector provided should only include pedestal samples and not signal.

Parameters
traceA std::vector containing the trace of the pixel to be analyzed

Optional parametes:

Parameters
tWindowThe size of the window in 10s of ns to use. Default is 20 samples.
padThe number of samples to skipa after each time window
isUnCorrelatedA bool specifying whether to skip the pad number of samples or not
Returns
A float with the average of the different window samples

Public method to linearly interpolate between 2 data points.

The linear interpolation is done the following way

f(x) = ((y2-y1)/(x2-x1))*x + (f(x1)-((y2-y1)/(x2-x1))*x1)

Parameters
x1A double of the x coordinate of the first point
y1A double of the y coordinate of the first point
x2A double of the x coordinate of the second point
y2A double of the y coordinate of the second point
xNewA double of the x coordinate of the point to find, between x1 and x2. (There is no strict need for xNew to be within the range, but the result will not be an interpolation but an extrapolation.)
Returns
A double with the y coordinate corresponding to xNew
