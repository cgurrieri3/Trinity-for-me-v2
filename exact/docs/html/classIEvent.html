Detailed Description

Class that contains the raw data plus the auxilliary data.

Inherits from class Event and adds new data to each of the events based on the auxilliary data obtained from the State Messages. Data contains information about the telescope conditions at the time of trigger

Public method to fill in most of the member variables.

Vectors have size row x cols, depending on the csv file used to obtain them. Each of the rows corresponds to a different time stamp and each column to different values of the different auxilliary data sources. Column 0 should be the timestamp
