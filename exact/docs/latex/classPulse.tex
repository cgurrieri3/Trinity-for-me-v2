\subsection{Detailed Description}
The main class for analyzing a trace obtained from data acquisition. 

\hyperlink{classPulse}{Pulse} is the backbone of the anlaysis software in Ex\+A\+CT. It analyzes the traces provided and obtains the information thaty characterize the particular signal.
