\subsection{Detailed Description}
Class used for combining Trigger Board data and Co\+Bo data (Trigger information and raw data) 

Class stores the raw data from the Co\+Bo as form of traces for each event and sorted according to pixel number. Each object also contains trigger information like time of trigger and trigger cell that caused the readout.
