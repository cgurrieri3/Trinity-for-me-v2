\subsection{Detailed Description}
Class with methods used in analysis of the traces obtained for each of the events. 

All methods require the same arguments to be used. Some of the arguments are optional. Some methods have been overloadad in order for them to be used under different conditions and applied to different data sets.

Public method to identify if the digitized data from the camera constitutes a bad event. 

When the system overtriggers (the trigger rate is higher than the electronics can handle), the beginning of the traces overflows the digitizer. This is shown as a flat line pedestal. The method checks all the traces in an event to identify if it constitutes one of these overflowed events.
